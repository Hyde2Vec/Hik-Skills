# Hik-Skills

可持续扩充的 Skill 合集。每个技能放在独立目录中，按需安装和使用。

## Skills

| Skill | 状态 | 说明 |
| --- | --- | --- |
| [产品运营周报](skills/product-weekly-report/) | 试用 | 中文产品运营周报，支持灵活统计口径、多类报告约定、手机长图、响应式网页和历史版本。 |

## 目录与使用

每个技能位于 `skills/<skill-name>/`，以 `SKILL.md` 为 Agent 入口；使用说明、适用环境与已知限制见该技能的 `README.md`。

将需要的技能目录放入所用 Agent 的技能搜索路径，并按该平台要求注册。后续新增技能继续使用同样的独立目录结构。

第三方资源的许可证和来源随对应技能保留。
