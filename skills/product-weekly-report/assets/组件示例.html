本页是组件目录：所有名称、数字与事件均为演示数据，仅用于说明表达方式。

报告组件示例

表达组件目录|配合 报告样式.css 使用|组件按需选用、自由组合

这些组件是表达手段，不是固定章节。手机 OA 阅读的 PNG 长图是第一产物，HTML 是同内容的网页副本：组件在 390/768/1440 等宽度自适应重排——手机纵向可读，宽屏并列信息网格分栏，内容、顺序与默认可见状态在所有宽度一致；不用折叠、不用横向滚动承载必要信息。一期报告可以只用其中两三样，也可以把组件嵌套出本页没有的布局。选择依据永远是已确认主稿的内容结构，不是组件清单本身。片段中的类名均为 报告样式.css 中已定义的样式。

页面骨架

适用：每份报告的最外层。报头放标题与周期、范围等一行口径；lead 放开场段（周期、范围、总体说明）；report-foot 放文末说明（口径、来源、编制信息）。三者都可省略，顺序固定为先头后尾。

<div class="page">
  <header class="report-head">
    <h1>产品运营周报</h1>
    <p class="head-meta">报告周期：…<span class="meta-sep">|</span>统计范围：…</p>
  </header>
  <div class="lead"><p>开场说明段…</p></div>
  <!-- 各章节 -->
  <footer class="report-foot"><p>口径与来源说明…</p></footer>
</div>

章节与标题层级

适用：h2.sec 是一级章节（一个产品、一个专题、一张总表都可以是章节）；h3.sub 是章节内小标题。章节数量和名称完全由本次内容决定，长产品名会自动换行，不需要为排版缩短名称。

章节内小标题的样子

小标题下直接接正文段落即可，不需要额外容器。

<section>
  <h2 class="sec">一、超长名称的产品或专题标题会自然换行不受影响</h2>
  <h3 class="sub">本期进展</h3>
  <p>正文段落…</p>
</section>

指标组

适用：一组并列的关键数字（出货、订单、商机、金额等）。列数随指标个数自适应；单位放 .unit；口径或比较基准放 .metric-sub；缺数必须显示“未提供”（.metric-value na），不留空不凑数。数字保持来源原样，不为对齐改写法。

年度累计出货（演示） 1,090万元 口径：含海外子公司
本期出货（演示） 40万元
在手订单（演示） 未提供 来源缺该字段，待补充 
<div class="metrics">
  <div class="metric">
    <span class="metric-label">指标名</span>
    <span class="metric-value">1,090<span class="unit">万元</span></span>
    <span class="metric-sub">口径或基准说明（可省）</span>
  </div>
  <div class="metric">
    <span class="metric-label">缺数指标</span>
    <span class="metric-value na">未提供</span>
  </div>
</div>

表格（仅少列表）

适用：列数少（约 2–4 列）、文字列可换行的结构化数据，在 390px 阅读宽下整表可见。务必包一层 .table-wrap。数字列加 class="num" 右对齐等宽、数值不拆行；表注用 .caption 写口径与范围。列多的宽表不要塞进报告：改用键值行列表逐条表达（见下节），全部字段保留为文字；表格横向溢出会被检查工具判为失败并要求重排。

项目（演示）状态金额（万元）
某园区智能化改造项目三期工程进行中126.50
某客户年度框架采购已签约1,024.00

表注写法示例：金额单位为万元，范围为选定产品（演示数据）。

<div class="table-wrap">
  <table>
    <thead><tr><th>项目</th><th class="num">金额（万元）</th></tr></thead>
    <tbody><tr><td>…</td><td class="num">126.50</td></tr></tbody>
  </table>
  <p class="caption">口径、范围、来源说明。</p>
</div>

事件列表与状态标签

适用：本期事件、进展、事项逐条列出。.tag 标状态（新增 / 更新 / 风险 / 待核对等），标签只帮助扫读，文字本身仍须完整表达事实与条件。来源文本本身多行时给条目加 .keep-lines 保留换行。没有事件时写 .empty-note 明示，不留空白。

  • 本期新增某项目完成现场测试，待客户确认，预计月底出货（演示事件）。
  • 持续推进某项目方案评审通过； 下一步进入商务谈判阶段（演示事件，保留来源换行）。
  • 待核对某记录本期消失，需确认是更名还是跟踪范围调整（演示事件）。

空状态示例：本期无新增可报告进展。

<ul class="events">
  <li><span class="tag tag-accent">本期新增</span>事件文字，保留否定与条件…</li>
  <li><span class="tag tag-info">持续推进</span><span class="keep-lines">多行
进展文字</span></li>
</ul>
<p class="empty-note">本期无新增可报告进展。</p>
<!-- 标签变体：tag（灰）/ tag-accent（金铜）/ tag-info（灰绿）/ tag-strong（墨蓝） -->

键值行列表

适用：台账式明细与宽表的替代：名称居左、数值居右对齐（出货明细、费用明细、分地区小计）。数值用 .row-side，附属信息放 .row-detail；字段多时在 .row-detail 上加 .keep-lines 分行罗列全部字段（原多列宽表按此逐条转换，字段一个不少）。

  • 某项目（演示） 某地区 · 某客户 18 台
  • 名称很长的项目会占据左侧空间并换行（演示） 字段一：某值 · 字段二：某值 更多字段逐行列出，完整保留 2 万元 
<ul class="rows">
  <li>
    <span class="row-main"><span class="row-name">项目名</span>
      <span class="row-detail keep-lines">字段逐行
分行列出</span></span>
    <span class="row-side">18 台</span>
  </li>
</ul>

说明区

适用：口径说明、数据限制用默认 .note（灰绿）；需特别关注的风险、待确认事项用 .note-attention（金铜）。不用红色警告样式；说明区是正文的一部分，内容须与正文事实一致。

口径说明（演示）

本期统计仅覆盖选定产品，明细合计与来源总计存在 0.5 万元差异，原因待核对。

需关注（演示）

某项目预计出货不等于已出货；客户验收完成前不确认收入。

<div class="note">
  <span class="note-title">口径说明</span>
  <p>说明文字…</p>
</div>
<div class="note note-attention">
  <span class="note-title">需关注</span>
  <ul><li>事项一</li></ul>
</div>

不使用折叠

原则：图片与网页必须同内容、同布局，因此报告正文不使用 details 折叠——明细、附录、核对依据全部默认可见，用小标题（h3.sub）＋键值行／少列表直接展开排。内容长就分段分页呈现，不靠点击展开。机读 JSON 放 <script type="application/json"> 非呈现节点，页面上不显示代码块。

辅助类与组合

适用：正文内的细节控制，以及用基础元素组合出本页未列出的布局。

  • .num：正文内嵌数字等宽（如“较上期 +12.5%”）。
  • .muted / .faint：次级与弱辅助文字；.small：小字；.nowrap：短数值不换行；.keep-lines：保留文字中的真实换行。
  • 组件可嵌套：说明区里放列表、章节里连续放指标组＋事件列表＋说明区。
  • 基础元素（段落、ul/ol、strong）可直接使用；需要新布局时按语义组合类名，不引入本样式表之外的机制。
<p>较上期 <span class="num nowrap">+12.5%</span>，<span class="muted">口径同上。</span></p>

图表（可选）

适用：本次报告确实需要趋势、对比等图形时；普通报告不引用图表文件。图表用本地 vendor/echarts.min.js ＋ 图表.js 的 初始化图表(容器, option)，容器用 .chart。静态图必须表达完整要点（tooltip 等交互只是增强）；每张图配同口径、默认可见的数据表与文字摘要，机读 JSON 放相邻 application/json 节点，缺失写 null 不按 0。完整可运行示例见 示例-分析.html，打包与数据纪律见呈现规范的“图表（可选）”一节。

<script src="vendor/echarts.min.js"></script>
<script src="图表.js"></script>
<div class="chart" id="chart-1"></div>
<script>
初始化图表(document.getElementById('chart-1'), {
  tooltip: { trigger: 'axis' },
  xAxis: { type: 'category', data: ['…'] },
  yAxis: { type: 'value', name: '万元' },
  series: [{ name: '本期', type: 'line', data: […, null, …] }]  // null = 缺失断点
});
</script>
